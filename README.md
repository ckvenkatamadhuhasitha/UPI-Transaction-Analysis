# UPI Transactions Analysis – Power BI

##  Overview
This project analyzes **UPI transactions** across major Indian cities using **Power BI**.  
The dashboard provides insights into **transaction types, device usage, bank performance, and success rates**, helping understand digital payment patterns.

##  Features
- Transaction distribution by **city, device type, and bank**
- Success vs failure analysis of UPI transactions
- Average remaining balance calculation using **DAX measures**
- Interactive visualizations: maps, bar charts, and pie charts
- Clear identification of **transaction trends across banks and cities**

##  Tools & Technologies
- **Power BI** – Data visualization and dashboard building  
- **DAX** – Measures for averages, comparisons  
- **SQL / Power Query** – Data cleaning & transformation

 Insights Gained
- Bangalore and Hyderabad show higher transaction volumes.  
- Mobile devices dominate UPI usage compared to laptops/tablets.  
- Most banks maintain similar balance ranges, but **Axis Bank** and **HDFC Bank** lead in average balances.  
- Overall success rate: ~80%, with failures mainly due to transaction type mismatch.
